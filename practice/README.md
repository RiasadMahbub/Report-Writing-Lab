# Practice Drafts

Drop your own practice pieces here, one file per attempt, named like:

```
2026-09-03-epi-country-brief.md
2026-09-10-nature-risk-note.md
```

Suggested first exercise: pick ONE narrow, specific question — e.g. "how has
[country]'s EPI score changed since 2018, and what's driving it" — and write
a one-page brief using `templates/research-note-template.md`. Then check it
against `style-guides/comparison.md`'s "biggest style tell" section: does
every claim carry a number and a source?
